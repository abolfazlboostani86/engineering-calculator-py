# ماشین حساب مهندسی

یک ماشین حساب مهندسی با زبان برنامه‌نویسی پایتون.

## امکانات و عملیات ریاضی
- جمع دو عدد
- تفریق دو عدد
- ضرب دو عدد
- تقسیم دو عدد
- محاسبه توان
- محاسبه باقیمانده تقسیم
- محاسبه سینوس (Sin)
- محاسبه کسینوس (Cos)
- محاسبه تانژانت (Tan)
- محاسبه کتانژانت (Cot)
- محاسبه فاکتوریل (Factorial)
- محاسبه جذر (Square Root)
- محاسبه لگاریتم پایه ۱۰ (Logarithm)
